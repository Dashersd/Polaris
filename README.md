## 🌟 Overview

**Polaris** is an immersive, high-end digital showroom and intelligence synthesis platform designed for the avant-garde frontier of fashion. Drawing inspiration from the North Star, Polaris acts as a style compass, merging structural minimalism, speculative apparel design, and real-time semantic synthesis into a single, breathtaking responsive web experience.

The interface features an architectural grid system, subtle glassmorphism, harmonious deep palettes (`#425873` steel blue and matte obsidian), and immersive video looping technology.

---

## 🛠️ Tech Stack

Polaris is constructed utilizing state-of-the-art web technology for speed, type safety, and premium fluidity:

*   **Framework**: **React 19.0.1** (leveraging cutting-edge hooks and performance metrics).
*   **Bundler & Dev Server**: **Vite 6.2.3** (providing ultra-fast Hot Module Replacement and modular tree-shaking).
*   **Language**: **TypeScript** (fully type-safe project structure for extreme reliability).
*   **Styling & Design System**: **Tailwind CSS v4.1.14** (compiled natively via the new `@tailwindcss/vite` high-performance plugin).
*   **Micro-Animations & Transitions**: **Motion v12.23.24** (the unified framer-motion architecture providing smooth spring physical states and entrance/exit page transitions).
*   **Icons**: **Lucide React** (pixel-perfect vector interface iconography).
*   **Custom Components**: **BoomerangVideo Player** (a custom React component engineered to play looping MP4 clips forwards and backwards seamlessly via RequestAnimationFrame coordinates to achieve organic fluid motion).

## 🚀 Running Locally

Follow these quick commands to spin up the local development environment:

### Prerequisites
*   [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1.  **Clone the repository and install dependencies**:
    ```bash
    npm install
    ```
2.  **Start the local development server**:
    ```bash
    npm run dev
    ```
3.  **Open in your browser**:
    Navigate to `http://localhost:3000/` to experience Polaris live.

### Building for Production
To generate a fully optimized production build:
```bash
npm run build
```
The compiled assets will be built into the `dist/` directory, optimized and ready for immediate server deployment.
